# Career Fit Coach：AI 岗位匹配、JD 分析与简历优化 Skill

一份职位描述看起来什么都要，很多人要么直接放弃，要么让 AI 把简历改到不像自己。真正需要的是一份诚实的证据匹配：哪些要求你已经证明，哪些可以迁移，哪些确实是硬缺口。

`career-fit-coach` 是一个面向求职者的开源 AI 岗位匹配、JD 分析和简历优化 Agent Skill。它用职位要求和你的真实经历建立证据矩阵，再给出直接申请、补材料、暂缓或放弃的明确建议。兼容 Codex、Claude Code、Cursor、OpenCode 等支持 `SKILL.md` 的工具。

## 它能做什么

- 从职位描述中区分硬门槛、核心能力和偏好项
- 用简历、项目和成果建立证据矩阵
- 判断“直接投 / 补材料后投 / 暂缓 / 不投”
- 改写简历要点，但绝不编造经历和数字
- 生成面试中最可能被追问的证据缺口

## 使用示例

```text
用 $career-fit-coach 分析这个岗位是否值得投。
下面是 JD 和我的简历，请先给判断，再告诉我简历最该改哪三处。
```

## 安装

```bash
cp -R skills/career-fit-coach ~/.codex/skills/
```

安装后调用 `$career-fit-coach`。

## 与普通简历润色的区别

它不会为了提高“匹配度”偷偷增加你没做过的技术、管理人数、收入贡献或工作年限。每一条建议都要能回到真实证据。

## 适用场景

- 分析职位描述，判断这个岗位值不值得投
- 对比 JD 和简历，找出硬门槛、核心能力与证据缺口
- 针对目标岗位优化简历和项目经历
- 转行、升职或跨行业申请的可迁移能力分析
- 准备面试中最可能被追问的经历和 STAR 故事

## 常见问题

### 它能给岗位匹配度打分吗？

它更强调证据而不是一个看似精确的百分比。输出会区分直接证据、迁移证据、弱证据和缺失证据，并给出申请结论。

### 会帮我补充没有做过的经历吗？

不会。职位、技术、学历、年限、团队规模和业务结果都必须来自用户提供的真实材料。

### 只有 JD，没有完整简历能用吗？

可以先拆解岗位要求；补充经历后再生成完整证据矩阵和简历修改建议。
